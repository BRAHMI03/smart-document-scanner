# Deployment

1. Open the GitHub repository.
2. Upload/replace:
   - `index.html`
   - `assets/app.js`
   - `assets/style.css`
3. Keep `assets` as a folder. Do not rename it.
4. Settings → Pages → Deploy from branch.
5. Branch: `main`; folder: `/ (root)`.
6. Save and wait for GitHub Pages to finish building.
7. Open the HTTPS Pages URL.
8. On mobile, allow camera permission.

If an older `app.js` or `style.css` exists in the repository root, it is not used by this version. The active files are inside `assets/`.
