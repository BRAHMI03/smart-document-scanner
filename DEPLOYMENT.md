# QUICK PUBLISH CHECKLIST

## Fastest
1. Go to GitHub and create a new repository.
2. Upload:
   - index.html
   - assets/style.css
   - assets/app.js
   - README.md
3. Repository Settings → Pages.
4. Source: Deploy from branch.
5. Branch: main / root.
6. Wait for deployment.
7. Open the HTTPS URL on your phone.
8. Allow Camera permission.
9. Test with a sample/non-sensitive document first.

## Recommended testing
- Chrome Android
- Safari iPhone
- Chrome/Edge Windows
- Laptop webcam
- Image upload
- Excel export
- Dark/light theme
- Delete individual record
- Delete all records

## Security before real customer use
Do not treat this starter as a compliance-certified KYC product. Add consent, authentication, encryption, server-side security, retention/deletion controls, audit logs, and appropriate legal/regulatory review before storing real identity documents.
