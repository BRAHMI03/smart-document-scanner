# Deployment — v4

1. Download the v4 ZIP.
2. Extract it.
3. In your GitHub repository replace `index.html`.
4. Open the `assets` folder and replace `app.js` and `style.css`.
5. Keep the exact folder structure:

smart-document-scanner/
  index.html
  assets/
    app.js
    style.css

6. GitHub Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
7. Save and wait for the Pages deployment.
8. Open the HTTPS site and hard-refresh (`Ctrl+F5` on Windows).

Camera access requires a secure context such as HTTPS and browser permission.
